# Lakay Flight (Aviator-style demo)

Play-money instant crash game inspired by Aviator UX (Paryaj Lakay reference).

## Run

```bash
cd aviator-game
npm install
npm run dev
```

Open the local URL Vite prints (default `http://127.0.0.1:5173`).

## Mode test

In the **Mode test** panel you can force the next crash multiplier (e.g. `2.00x`), optionally lock it for every round, or return to random. This only affects the local demo — not any real casino site.

## Notes

- Demo credits only — no deposits, withdrawals, or real-money gambling
- Local RNG with a house edge; not connected to any casino backend
